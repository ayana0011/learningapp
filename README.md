# フレーズ暗記（韓国語）

好きな動画・ライブの字幕から、フレーズ単位の暗記カードを作るアプリ。料金なしで使える。

## 公開版（スマホでも使える）
https://ayana0011.github.io/learningapp/ — main に push すると GitHub Actions で自動公開。
- iPhone: Safari で開く → 共有 →「ホーム画面に追加」でアプリのように使える（オフラインでも開ける）
- データは端末ごと。設定 →「同期ファイルを書き出す」→ AirDrop → もう片方で「読み込んで合わせる」（新しい方が残る・消したものは消えたまま）

## Claude Code で自動作成（パソコンだけ）
コピペの代わりに、このパソコンの Claude Code（`claude -p`、Sonnet）でカード・画像の解説・単語の意味を自動で作る。プランの使用量にカウントされる。
```bash
node ~/learningapp/helper/server.mjs
```
起動中はアプリに「🤖 Claude Code で自動作成」ボタンが出る。取り込み画面に YouTube の URL を貼ると「🤖 字幕を自動で取り込む」も出る（韓国語字幕がある動画だけ。初回のみ `sh ~/learningapp/helper/setup.sh` で準備）。127.0.0.1 だけで待ち受け、公開版と localhost のアプリからの依頼だけに答える。初回に Chrome が「ローカルネットワークへのアクセス」を聞いてきたら許可する。`claude` のログインが切れていたら、ターミナルで `claude` →`/login`。

## 手元で起動（開発用）
```bash
cd app
npm install   # 初回だけ
npm run dev
```
ブラウザで http://localhost:5173 を開く。

## 使い方
1. **取り込み**: YouTube の概要欄「文字起こしを表示」の字幕をコピーして貼る（.srt / .vtt / .txt も可）。相づち・[音楽] などは自動で除く
2. **範囲を選ぶ**: 長い素材は約12分ごとの区切りを選べる。行クリックで開始、Shift+クリックで終了
3. **カードを作る**: 「プロンプトをコピー」→ claude.ai（Sonnet 推奨）に貼る → 答えをまるごと貼り戻して「カードに追加」
4. **暗記**: スペースで答え、`1` もう一回 / `2` だいたいOK / `3` 覚えた。「もう一回」は数枚後に再出題。復習は 1→3→7→14→30→60 日

5. **単語デッキ**: カード裏面の単語の「＋」、または tblfan 拡張の「＋単語を保存」で集まる。意味がない単語は「意味づけプロンプト」を claude.ai に貼って一括で意味を付ける
6. **画像から**: 取り込み →「🖼️ 画像」で、韓国語が写ったスクショ・写真を選ぶ（⌘V で貼り付けも可）→「画像をコピー」「プロンプトをコピー」を claude.ai に貼る → 答えを貼り戻すと、書き起こし・訳・ポイント解説とカードができ、単語も単語デッキに入る
7. **Claude で調べた答えから（スマホ向け）**: claude.ai に「プロジェクト」を作り、取り込み →「💬 Claude」にある指示文を入れておく。そのプロジェクトで韓国語の画像・文章を聞くと答えの最後に JSON が付くので、コピー → アプリの「📋 コピーした答えを貼り付け」→「単語帳に追加」
8. **目標**: 設定で「◯日で◯語」を決めて「今日から始める」→ ホームに進み具合と1日の目安が出る（覚えた単語＝単語デッキで覚えた単語＋覚えたフレーズに入っている単語）

データはこのブラウザの中（IndexedDB）だけに保存。設定画面の同期ファイルがバックアップにもなる。

## tblfan 用 Chrome 拡張（`extension/`。リポジトリには入れず、このパソコンだけに置いている）
韓国語と日本語の字幕を同時に表示し、見ている間の字幕を記録して暗記アプリに送る（自分用）。

**入れ方**: Chrome で `chrome://extensions` → 右上「デベロッパーモード」オン →「パッケージ化されていない拡張機能を読み込む」→ `extension` フォルダを選ぶ

**使い方**
1. tblfan のライブ・リプレイを開いて再生（tblfan 側の字幕はオフにすると見やすい）
2. 動画の下に、短く区切った韓国語＋日本語の字幕が出る
3. **単語をクリック** → 一時停止して意味を表示（Chrome 内蔵の翻訳機能・無料）。「＋単語を保存」「Naver辞書」も
4. 覚えたい文は ☆。**≡（履歴）** を開くと、過ぎた字幕の一覧から ☆ を付けたり、時刻をクリックしてその文に戻れる
5. 拡張アイコン →「暗記アプリに送る」（送り先は公開版。ポップアップの「暗記アプリの URL」で変更可）→ 取り込み画面に ☆ 付きで入る
6. ポップアップから SRT（韓／日／韓日）保存、表示言語・文字サイズ・自動一時停止の設定

**キー**: `S` ☆ ／ `R` この文をもう一度 ／ `A` 前の文 ／ `P` 発話が終わるたびに一時停止 ／ `H` 履歴 ／ `Esc` 単語の意味を閉じる

**しくみ**: プレイヤーが受け取っている字幕データ（動画の timed metadata に入っている5言語の字幕）を読んで表示・記録するだけ。ログイン情報・Cookie・動画データには触れず、tblfan の API も叩かない。記録した字幕は自分の勉強用だけにして共有しない。

**制限**: 記録できるのは再生（読み込み）した部分だけ。全画面表示では2段字幕は出ない。単語の翻訳は Chrome 内蔵の翻訳（Translator API, Chrome 138 以降）を使うので、初回は翻訳データのダウンロードに少し時間がかかる。使えない環境では Naver辞書へのリンクだけ出る。

**テスト**: `node --test extension/captions.test.js`
